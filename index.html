On GitLaunch, on Launch

Launch a coin for a GitHub account.

The coin lists here. The master wallet creates it on Launch, so the chart shows that wallet as the dev. The numeric id GitHub assigns is who can claim. One percent of each trade accrues there.

Launch Coins Claim

Where a trade goes

  1. 1% Buys the coin and burns it. The master wallet is the buyer, so it shows up as the dev.
  2. 1% Burned by the platform.
  3. 1% Accrues to the GitHub account. Claim sends it. The next trades start a new balance.

GitLaunch sits on Launch. The GitHub id is the claim. This site stores the launch. The master wallet has not signed a create or a payout.
