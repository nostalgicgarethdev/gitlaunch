Privacy

27 Oct 2026. What the site keeps, and what it leaves alone.

Sign-in

Launch uses X. Claim uses GitHub. Each sign-in stores the numeric id and the login, and nothing else from that account. The access token is not kept. The cookie lasts 14 days, is HttpOnly, and is only for this site.

A launch

When a coin is created, the site stores:

  • Name, ticker, and logo. The logo is a small image.
  • The GitHub login and numeric id that can claim it.
  • The X id and login that launched it, so the 10-minute limit can be checked.
  • Optional Twitter handle and website, if you typed them.
  • The mint address, and the claim amounts already paid.

A claim

The Solana wallet you paste is used as the destination for that claim. It is stored with the claim record so the payout can be checked. GitHub does not receive the tokens.

What is public

A listed coin's name, ticker, mint, GitHub login, and metadata are public. That is how the coin shows on the site and on the chain. Session cookies are not public. The site does not sell this data.

Cookies

The site sets a session cookie when you sign in, and a short-lived cookie while X or GitHub sends you back. There is no ad tracker and no analytics cookie.

Questions go to @usegitlaunch.

One master wallet is the dev on every coin. A GitHub account claims only the coins linked to it.
